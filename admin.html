📋 How to use this CMS

  1. Add, edit, or delete products using the buttons below.
  2. When done, click Export / Save JSON in the sidebar.
  3. Copy the JSON and replace the contents of your products.json file.
  4. Save the file — the website updates automatically!

📋 How to manage resources

  1. Add, edit, or delete resources using the buttons below.
  2. When done, click Export / Save JSON and save the updated resources.json.
  3. Upload thumbnail images to the Resource_Thumbnails/ folder in GitHub.
  4. Upload PDF Catalogs to Resource_PDFs/Catalogs/ in GitHub.
  5. Upload Product IFUs to Resource_PDFs/IFUs/ in GitHub.
  6. Upload Educational Material PDFs to Resource_PDFs/Education/ in GitHub — only needed if you're attaching a PDF instead of a URL.
  7. The filename you enter in the CMS must exactly match the file uploaded to GitHub.
